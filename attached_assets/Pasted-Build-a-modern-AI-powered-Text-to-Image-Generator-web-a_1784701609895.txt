Build a modern AI-powered Text-to-Image Generator web application with a beautiful UI and production-ready code.

Tech Stack:
- Frontend: React + TypeScript + Vite
- Styling: Tailwind CSS + Shadcn UI
- Backend: Node.js + Express
- Database: PostgreSQL (NeonDB) with Prisma ORM
- Image Generation API: OpenAI Images API (GPT Image 1) or Stability AI (make API configurable)
- Authentication: Clerk or Supabase Auth
- Storage: Cloudinary (or local storage for development)
- State Management: TanStack Query
- Form Validation: React Hook Form + Zod

Design Requirements:
- Premium modern UI inspired by Midjourney, Leonardo AI, Ideogram, and Flux.
- Dark mode by default.
- Glassmorphism cards.
- Animated gradients.
- Smooth Framer Motion animations.
- Fully responsive.
- Professional typography.
- Beautiful loading skeletons.
- Mobile-friendly.
